## Practical consultation provenance

A new persistent Codex conversation built an isolated synthetic support-dashboard
handler using Python's standard library. Support staff inspect invented orders;
a separate billing service owns mutations and their audit trail. The agent chose
GET/HEAD/OPTIONS, rejected writes, wrote DESIGN.md, and ran five passing tests.
The project contains no real customer data, credentials, or work-project content.

The film-making agent then used Pika to consult that exact native UUID in an
ephemeral side. The complete answer in consultation.js is verbatim. The displayed
question omits only these formatting and safety instructions:

> Answer from the work you just did, in at most 45 words of plain prose. No tools or file changes.

No endpoint rationale was supplied in that question. The answer correctly
recovered the billing-ownership decision from inherited context. This illustrates
context reuse, not a benchmark proving a fresh model could never infer the answer.
It is one turn, local, with the parent parked. Waiting is omitted. The diagram is
an illustrated skill workflow, not a recording of the user's coding interface.

External capture scripts compared the parent's SHA-256 before and after, and
compared a path-to-hash manifest of every demo-project file. Both matched. Pika's
terminal receipt confirmed discarded: true and cleanup: complete. Its ordinary
parent_transcript_unchanged field was null: do not conflate that receipt with the
separate measurement. No claim of simultaneous coding or universal immutability
is made. Raw target identifiers and capture receipts remain in ignored local files.

The first capture attempt exposed a Codex paginated-parent fork requirement:
excludeTurns: true. It failed before delivery, with cleanup complete and retry
safe. The subsequent capture used the small compatibility fix and succeeded.
This flag excludes turns from the API response, not the side's inherited context.
Release that fix before publicly promoting the affected workflow with an install
command; the current v0.5.0a3 release does not contain it.

## Separate cross-server evidence

Previously recorded Codex and Claude tests each completed two turns, retained a
synthetic nonce between turns, and confirmed cleanup. The external scripts
compared parent transcript fingerprints and tracking flags before/after and
reported equality. These tests support the later cross-server statement only;
the support-dashboard consultation is not presented as remote.

## What changed through Alchemy

1. Lead with the value of expertise the viewer already has.
2. Show a familiar decision, not an explanation of Pika internals.
3. Make preservation the emotional payoff, with scoped evidence.
4. Make the current agent the protagonist and reveal the bundled skill early.
5. Offer a small first experiment: one conversation, on one machine.
6. Explain attention in human terms, not a tour of status labels.

No posting, push, release upload, or installation changes are made by rendering.
