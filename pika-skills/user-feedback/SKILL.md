# Pika feedback

Use `/feedback Your note` whenever something should change. Describe what happened
and what you wanted instead, in as much or as little detail as you like.

Pika appends your exact note, the UTC date and current scope to `user_feedback.md`
in your assistant profile. Earlier entries stay intact. A save confirmation means
the file was written; it does not mean the issue has been fixed.

Only the note you submit is recorded. Feedback does not automatically capture the
conversation, change Pika's guidance, or make a model call. The file is a product
feedback log for later review, separate from assistant memory.
