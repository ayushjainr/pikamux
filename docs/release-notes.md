Pika is now a small native Rust application.

- One live board for Codex, Claude Code, and OpenCode.
- Return to a conversation by name in its original agent interface.
- Let agents discover and privately consult relevant project expertise.
- Monitor and consult across trusted SSH and Tailscale machines.
- Faster startup and redraws, with low background CPU and memory use.
- Verified downloads, included agent-convo skill, and reversible native updates.

Install on macOS or Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/ayushjainr/pikamux/main/install.sh | bash
```

The Windows artifact is an experimental client for pairing with a Pika host.
