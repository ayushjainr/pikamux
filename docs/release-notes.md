Reopen the right conversation. See its state at a glance.

- **Reliable reopening.** Old pane labels no longer block a uniquely verified
  live conversation. Provider helpers no longer displace the conversation's
  actual owner.
- **A live Pika label.** The return bar's **← Pika** label follows the current
  conversation's status, using the same colors as the board. Unavailable or
  stale status stays neutral.
- **What's next, at a glance.** When no conversation needs attention, the bar
  points to the newest ready conversation instead.
- **Safer recovery.** Competing owners and incomplete identity evidence still
  block opening. Recovery does not stop an agent or remove an old shell.

Update from the board's **Update now? [y/N]** offer, or run `pika update`.
Reopen the board after updating. Existing agents keep running.

Windows packages remain unsigned in this release. Managed endpoint security may
still block installation or launch; this release does not resolve that limitation.
